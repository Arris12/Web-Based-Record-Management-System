# Web-Based Record Management System

## Project Overview

A full-stack web application designed to simplify the recording, organization, retrieval, and management of resident information within a fictional city.

Originally developed during an internship in 2023, the application was later adapted for portfolio demonstration.

As the primary developer, I was responsible for both front-end and back-end development, including user interface design, database integration, and core system functionality.
---

## Technologies Used

- **Front-End:** HTML5, CSS3, JavaScript, Bootstrap, jQuery, AdminLTE 3.2.0
- **Back-End:** PHP
- **Database:** MySQL
- **Libraries and Plugins:** AJAX, Select2, PHPMailer
- **Development Environment:** XAMPP, Apache, Visual Studio Code
- **Version Control:** Git and GitHub
